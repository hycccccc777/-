# 上线部署手册（云服务器 + Docker Compose）

> 目标：把本项目从「演示环境」切换到「可对外运营的生产环境」。
> 生产与演示的唯一区别是 `SPRING_PROFILES_ACTIVE=druid,prod`，
> 它会启用 `ProductionGuard` 启动自检：默认密钥、通配 CORS、沙箱支付会直接拒绝启动。

## 一、上线前你必须准备

| 项 | 说明 |
| --- | --- |
| 云服务器 | 2C4G 起步，Linux（Ubuntu 22.04 / CentOS 均可），装好 Docker + Compose 插件 |
| 域名 | 已做 **ICP 备案**（国内服务器必须），解析到服务器公网 IP |
| HTTPS 证书 | 可用云厂商免费证书或 `certbot`（Let's Encrypt） |
| 支付方案 | 本版本默认「线下面交（4）」；接真实支付需商户号 + `CAMPUS_PAY_SECRET` |
| 腾讯云短信 | SecretId/SecretKey、短信应用 SdkAppId、签名、模板（模板含一个变量 `{1}` 即验证码） |
| 腾讯云 COS | 存储桶、SecretId/SecretKey、访问域名/自定义 CDN 域名 |

## 二、部署步骤

### 1. 拉代码

```bash
git clone <你的仓库> campus && cd campus
cp .env.example .env
```

### 2. 填 `.env`（关键项）

```ini
# 密钥（务必随机）
MYSQL_ROOT_PASSWORD=<强口令>
CAMPUS_JWT_SECRET=<openssl rand -hex 48>
CAMPUS_PAY_SECRET=<openssl rand -hex 32>

# 生产开关
SPRING_PROFILES_ACTIVE=druid,prod
CAMPUS_CORS_ORIGINS=https://your-domain.com
CAMPUS_PAY_METHOD=4

# 短信
CAMPUS_SMS_ENABLED=true
CAMPUS_SMS_PROVIDER=tencent
TENCENT_SMS_SECRET_ID=...
TENCENT_SMS_SECRET_KEY=...
TENCENT_SMS_SDK_APP_ID=...
TENCENT_SMS_SIGN_NAME=...
TENCENT_SMS_TEMPLATE_ID=...

# 对象存储
CAMPUS_STORAGE_TYPE=cos
TENCENT_COS_SECRET_ID=...
TENCENT_COS_SECRET_KEY=...
TENCENT_COS_BUCKET=<bucket-1250000000>
TENCENT_COS_REGION=ap-guangzhou
TENCENT_COS_PUBLIC_BASE_URL=https://cdn.your-domain.com
```

### 3. 启动

```bash
docker compose up -d --build
docker compose ps           # 确认 mysql/redis/backend/frontend 均 healthy
```

后端启动日志若出现 `[生产自检失败] ...`，按提示修 `.env` 后 `docker compose up -d` 重试。

### 4. 反向代理 + HTTPS

在宿主机用 Nginx 把 `https://your-domain.com` 反代到前端容器（默认 `5174`），
后端只在内网暴露，不要直接对公网开放 8080。

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    ssl_certificate     /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:5174;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

`CAMPUS_CORS_ORIGINS` 必须与这里的域名一致。

### 5. 首次数据

- 演示数据会随 SQL 初始化导入；正式运营前请清理演示商品、演示账号。
- 管理员账号：登录后可在「管理后台」做商品审核、用户查看。

## 三、上线检查清单

- [ ] `.env` 里 `CAMPUS_JWT_SECRET` / `CAMPUS_PAY_SECRET` 均为随机值（非默认）
- [ ] `SPRING_PROFILES_ACTIVE=druid,prod`，启动日志出现「生产配置自检通过」
- [ ] `CAMPUS_CORS_ORIGINS` 是真实域名，不含 localhost/通配符
- [ ] 接口文档已关闭：访问 `/v3/api-docs` 返回 404
- [ ] 域名 HTTPS 正常，HTTP 自动跳转 HTTPS
- [ ] 短信通道实测能收到验证码（用真实手机号）
- [ ] 图片上传后可用公网 URL 打开（COS + CDN）
- [ ] 下单 → 线下面交 → 确认付款 → 卖家交付 → 确认收货 全流程走通
- [ ] 备份定时任务已注册（`scripts/install-backup-task.ps1` 或 cron）
- [ ] Prometheus/Grafana/Alertmanager 已接告警接收端
- [ ] 关闭/清理演示账号，设置强口令管理员

## 四、回滚

```bash
docker compose down
git checkout <上一个稳定 tag>
docker compose up -d --build
```

数据库迁移由 Flyway 管理，回滚代码前先确认没有不可逆的 schema 变更。
