# 交付说明（给接收方）

> 一页说明：这是什么、怎么跑起来、账号在哪、证据在哪、还有什么没做到。

## 1. 这是什么

校易淘 —— 校园二手交易系统。前端 Vue 3 单页应用，后端 Spring Boot 4.1.0（基于若依扩展），数据层 MySQL + Redis。买家与卖家的完整交易闭环（浏览、收藏、购物车、下单、支付、发货、收货、退款）已打通并通过端到端验证。

## 2. 怎么跑起来

### 2.1 环境要求

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 27（运行）/ 17（编译） | 项目 `pom.xml` 目标是 17 |
| Maven | 3.9.x | 若本机没有，`启动后端.cmd` 会尝试使用 `%LOCALAPPDATA%\campus-maven` |
| MySQL | 8.0+（开发机为 26.7） | 需要两个库：`shop`（开发）、`shop_test`（测试） |
| Redis | 7.x | 默认 127.0.0.1:6379，无密码 |
| Node.js | 18+（开发机为 24.21） | 仅前端需要 |

### 2.2 三步启动

```bat
启动后端.cmd          :: 检查 MySQL/Redis → 定位 java/mvn → 构建 → 启动 :8080
启动前端.cmd          :: 缺依赖自动 npm install → 启动 :5174
检查服务.cmd          :: 后端/前端/文档/代理链路逐项自检
```

容器方式（不需要本机装 MySQL/Redis）：

```bat
docker compose up -d --build --wait
:: 访问 http://localhost，后端经 Nginx 反代
```

首次启动时 Flyway 自动建表并导入种子数据；`docker/mysql-init` 里也带了初始化 SQL。

### 2.3 验证是否正常

```bat
curl http://localhost:8080/api/v1/system/health
curl http://localhost:8080/actuator/health
```

再跑一次业务闭环，看到「待付款 → 待发货 → 待收货 → 已完成」就算通了：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\demo-business-loop.ps1
```

## 6. 多实例（可选）

docker compose -f docker-compose.yml -f docker-compose.scale.yml up -d --build --scale backend=2 --wait

- 统一入口 http://localhost:8088
- 响应头 `X-Instance-Id` 标明由哪个节点处理
- 本地无 Docker 时：`node scripts/lb-proxy.mjs --listen 8088 --backends 8080,8082`，验证 `scripts/demo-lb.ps1`

- 配置见 docs/ops/prometheus.yml、docs/ops/alertmanager.yml、docs/ops/alert-rules.yml（6 条规则）

## 9. 安全提示

- `application-druid.yml` 里的数据库密码有默认值，**生产环境必须用环境变量覆盖**（`CAMPUS_DB_PASSWORD`）。
- `certs/`、`backups/`、`logs/`、`.env` 都不入库，不要打包外发。
- 支付回调密钥 `CAMPUS_PAY_SECRET` 默认值是占位符，上线前必须替换。
