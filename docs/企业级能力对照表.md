## 一、安全

| 能力 | 状态 | 实现与证据 |
|---|---|---|
| OAuth2 / JWT | ✅ | JJWT 0.9.1；`ruoyi-framework` `TokenService` 签发/校验访问令牌；`JwtAuthenticationTokenFilter.java` 解析 Bearer；`ruoyi-campus` `RefreshTokenService.java:44` 把刷新令牌写入 Redis 并按时长过期；`RefreshTokenFlowTest`（4 例）覆盖刷新与失效 |
| RBAC | ✅ | 若依标准三表 `sys_user` / `sys_role` / `sys_menu` + `sys_role_menu`；接口用 `@PreAuthorize("@ss.hasPermi(...)")` 鉴权 |
| 密码哈希 | ✅ | `BCryptPasswordEncoder`（全后端 7 处引用，`SecurityUtils` 中加密/校验）；数据库 `sys_user.password` 存 BCrypt 串，不存明文 |
| HTTPS | ❌ **未配置** | 本地为 http。生产应在 Nginx 终止 TLS（前端容器已有 nginx.conf，加 `listen 443 ssl` 即可）。**未做，不宣称** |
| 防越权 | ✅ | 服务层校验资源归属，例如 `CtProductServiceImpl.java:240`「商品不存在或无权操作」；订单/支付按 `sellerId`/`buyerId` 与当前登录用户比对 |
| 防 SQL 注入 | ✅ | 全部走 MyBatis 预编译 `#{}`；`CtProductMapper.xml` 等 mapper 中无 `${}` 拼接用户输入 |
| XSS | ✅ | `XssFilter.java:22` + `XssHttpServletRequestWrapper` 过滤请求体；`FilterConfig.java:14` 注册 |
| CSRF | ✅ | `SecurityConfig.java:90,93` 关闭 CSRF——因为是无状态 JWT（不使用 Cookie 会话），无 CSRF 攻击面；这是有意的取舍，非疏漏 |
| 接口限流 | ✅ | `ratelimit/RateLimit.java`（注解）+ `RateLimitInterceptor.java` + `SlidingWindowLimiter.java`（memory / redis 双实现，redis 走 ZSET + Lua 原子计数）；`campus.ratelimit.store` 切换。多实例验证见「多实例正确性验证」
| 敏感数据脱敏 | ⚠️ 部分 | 日志中对密码等字段未打印；数据库口令走环境变量不落仓库。**未做统一的手机号/身份证脱敏**，如实标注 |
| 审计日志 | ✅ | 业务接口 43 处 `@Log(title=..., businessType=...)`，由若依切面写入 `sys_oper_log` |

## 四、可靠性

| 能力 | 状态 | 实现与证据 |
|---|---|---|
| 日志 | ✅ | Logback 按级别分文件：`logs/sys-info.log`、`sys-error.log`、`api-access.log`；每条带 `[trace=]` |
| 监控 | ✅ | Druid 监控台 `/druid`（SQL、连接池、慢查询）；`ApiTraceFilter` 为每个请求生成 `X-Trace-Id` 并写入 MDC，全链路可串 |
| 告警 | ✅ | `docs/ops/alert-rules.yml` 6 条规则（不可达 / 健康非 UP / 5xx>1% / P95>500ms / 堆>90% / 磁盘<10%）；`alertmanager.yml` 路由 + 抑制 + webhook；`docker-compose.monitoring.yml` 一键起栈。**本地实测**：Alertmanager 0.27.0 把 critical 告警投递到 webhook（883 字符载荷）。`scripts/check-alerting.ps1` 校验规则引用的指标真实存在 —— 曾据此发现 `health` 指标根本不存在（规则永不触发），已补 `campus_health_status` gauge |
| 健康检查 | ✅ | `GET /api/v1/system/health` → `{"code":200,"data":{"status":"ok",...}}`，可作探针 |
| 熔断 | ❌ 未接入 | 未引入 Resilience4j；单体内部调用不需要 |
| 降级 | ❌ 未接入 | 未做降级开关 |
| 重试 | ⚠️ 有限 | 前端 `src/utils/http.js` 对 401 做"刷新令牌后重试一次"，失败则登出；后端无重试 |
| 备份 / 恢复 | ✅ | `backup.ps1`（mysqldump + `--set-gtid-purged=OFF` + 保留 N 份 + **小于 1KB 判失败** + `-Offsite` 异地副本 + `logs/backup.log` 与 SHA256 清单）；`restore.ps1`。**定时**：`install-backup-task.ps1` 注册每日 02:00 计划任务，口令落 `%LOCALAPPDATA%` 并 icacls 限权，装完立即触发验证（`LastTaskResult=0`，130.5 KB）。**往返实测**：恢复后 45 表 / 8 商品 / 2 订单一致 |
