# 后端组员接收指南

## 这份包是什么

校易淘学生端前端源码和联调准备材料。技术栈沿用文档：Vue 3.4.38、Element Plus 2.5.6、Vite 6.4.1。没有后端源码、数据库脚本或密钥。

现有四个主页面为：首页、收藏、购物车、个人中心，商品详情和发布等通过弹窗交互。页面导航使用 hash，不依赖后端路由。

## 收到后怎么启动

1. 解压到任意普通目录，安装 Node.js 24。
2. 在包含 package.json 的目录执行 npm ci。
3. 执行 npm run dev，浏览器打开 http://localhost:5174。
4. 如需访问自己的 Spring Boot，复制 .env.example 为 .env.local，配置 DEV_API_TARGET 后重启。
5. 在浏览器开发者工具 Network 查看请求；页面目前主要使用本地数据，正常情况下不会自动调用业务 API。

可以直接用浏览器访问 http://localhost:5174/api/v1/system/health 检查代理。如后端沿用已建立的基础工程，应返回 code=200、data.status=UP。其他同学的后端若未提供此路由，需要自行增加或改用已实现的接口验证代理。

不要将 Vite 的本机地址 localhost 配到手机或其他电脑上；需要局域网访问时，显式设置开发服务器监听地址，并使用服务器的局域网 IP。目前默认仅允许本机访问。

## 双方分工

前端负责页面、请求调用、加载与错误提示、字段映射。后端负责真实身份、权限、商品审核、服务端分页、商品价格与库存、订单状态、支付验签和资金一致性。前端金额和用户 ID 均不能直接作为后端可信依据。

后端不需要修改 style.css 或商品插画来接接口。主要协作点为 src/api/index.js、src/composables/useMarketplace.js 和接口对接说明。

当前演示中的收藏仅在本地保存；原需求未给出收藏 API，不能把它当作后端漏做的已定接口。

## 优先交接的结果

请后端提供：
- 可访问的后端地址和 OpenAPI/Knife4j 地址。
- 各角色测试账号；通过团队约定的安全渠道传递，不写入源码包。
- 已完成接口清单、请求/响应示例及错误码。
- 商品、类目、学校、地址的测试数据和 ID。
- 支付沙箱的联调流程及回调地址安排，服务端私钥始终由后端保存。

对尚未一致的字段和规则，先在 docs/接口对接说明.md 记录结论，再同步代码。不要自行把本地昵称或 p1 等演示 ID 当成真实账号、真实商品 ID。
