# 联调验收清单

以下项目尚未因前端演示通过而自动验收，双方应填写实际结果。

- [ ] npm ci、npm test、npm run build 在后端同学机器通过。
- [ ] /api/v1/system/health 经前端代理返回实际后端响应。
- [ ] OpenAPI 版本、成功码、错误码、分页和 ID 类型一致。
- [ ] 商品列表、详情、类目和图片使用后端数据；加载、错误、空结果可见。
- [ ] 真实登录成功；错误密码、禁用、Token 过期正确处理。
- [ ] 商品审核状态与学校、类目筛选符合文档。
- [ ] 购物车条目 ID 与商品 ID 区分；失效商品不可下单。
- [ ] 地址管理、商品发布图片上传及审核流程接入。
- [ ] 下单由后端重算金额，并支持约定的幂等机制。
- [ ] 多卖家拆单后的所有子订单都能展示与支付。
- [ ] 支付结果从后端查询；取消与超时状态正确显示。
- [ ] 越权访问他人订单、商品、购物车在服务端被拒绝。
- [ ] 500、非 JSON、网络中断和超时不会显示“交易成功”。
- [ ] 刷新页面与退出登录行为符合认证方案。
- [ ] 移动端、键盘操作、正式域名 HTTPS 与 Nginx 代理验收。
- [ ] 售后、结算及商家/后台工作台另行完成并验收。

建议顺序：代理 → 商品 → 正式认证 → 购物车 → 地址/发布 → 订单 → 支付 → 履约/售后 → 后台与部署。
