面向后端组员，更新日期：2026-10-19。

本文帮助接收者快速找到页面、接口、配置与验证材料。当前工程为可运行的前端交互演示，真实业务 API 尚未接入页面；存在接口函数不代表真实登录、商品、订单和支付已经联调完成。

## 建议阅读顺序

1. README.md：了解完成范围，安装依赖并启动前端。
2. docs/后端接收指南.md：了解双方分工与接收步骤。
3. 本说明：熟悉文件位置和修改入口。
4. docs/接口对接说明.md：确认路径、字段、响应和未决事项。
5. src/api/index.js 与 src/api/http.js：检查具体调用入口与请求规则。
6. docs/联调验收清单.md：按业务顺序执行联调。

## 页面源码

| 文件 | 作用 | 修改场景 |
| --- | --- | --- |
| src/main.js | 创建 Vue 应用，注册 Element Plus 弹窗组件，引入组件和全局样式，挂载到 HTML | 增加全局插件、组件或样式 |
| src/App.vue | 组织首页、收藏、购物车和个人中心，绑定详情、身份、发布、结算弹窗 | 调整页面结构或交互绑定 |
| src/composables/useMarketplace.js | 集中管理本地演示状态、筛选、收藏、购物车、发布和演示订单；监听状态变化并保存到浏览器 | 接后端时替换数据来源、增加加载和错误处理 |
| src/style.css | 定义配色、字体、页面布局、组件样式和响应式断点 | 修改桌面或手机端界面 |
| src/components/Icon.vue | 根据 name 和 size 渲染搜索、购物车、收藏等 SVG 图标 | 增加图标或调整尺寸 |
| src/components/ProductArt.vue | 渲染书籍、耳机等演示商品插画 | 原型视觉调整；真实图片接入后另做图片展示 |
| src/data/products.js | 保存示例商品、分类与学校选项 | 更新演示数据；不能作为生产数据表 |
| src/utils/storage.js | 封装 localStorage JSON 读取和写入，对数据损坏、存储失败进行容错 | 调整演示状态持久化 |

Composable 是封装 Vue 响应式状态与逻辑的函数。本项目将状态从页面模板拆出，方便前端在不修改布局的情况下逐项接入真实接口。

## 后端对接代码

| 文件 | 作用 | 后端组员重点关注 |
| --- | --- | --- |
| src/api/http.js | 通用请求层：查询参数编码、JSON 请求、Token 注入、超时中止、统一响应解包、错误处理 | 成功码、HTTP 状态、业务错误码、X-Trace-Id |
| src/api/index.js | 集中声明认证、商品、购物车、订单、支付与健康接口入口；提供 setAccessToken、clearAccessToken | 路径、方法、请求字段、ID 类型、认证要求 |
| tests/http.test.js | 使用 Node 内置测试运行器验证请求层，覆盖 9 项场景 | 改请求规则后运行 npm test，防止破坏约定 |

HTTP 层返回响应中的 data，失败抛出 ApiError；调用方可读取 message、status、code、traceId。当前临时兼容文档中两种成功码 200 和 100000，最终需要双方统一。

正式 Token 仅由真实登录流程设置，当前昵称演示不会产生 Token。Token 暂存在内存，刷新后丢失，刷新认证与会话恢复尚未实现。不要用本地昵称或 localStorage 数据代替后端认证。

预留调用链：

    App.vue 页面
        → useMarketplace.js 状态与交互
        → api/index.js 具体接口
        → api/http.js 统一请求
        → Vite / Nginx 代理
        → Spring Boot 后端

当前演示主要是 App.vue → useMarketplace.js → 示例数据与 localStorage，还没有连接上面完整的业务调用链。原基础后端健康接口已经做过独立联通验证。

## 入口和配置

| 文件 | 作用 | 注意事项 |
| --- | --- | --- |
| index.html | 浏览器入口，提供 id=app 的挂载节点，加载 main.js | 通过开发或静态服务器访问，不直接双击运行 |
| package.json | 声明依赖与 dev、test、build、preview、handoff:pack 命令 | 新增依赖需团队确认必要性 |
| package-lock.json | 锁定依赖版本，支持 npm ci 可复现安装 | 由 npm 维护，通常随 package.json 一起提交 |
| vite.config.js | 配置 Vue 编译、开发端口、后端代理和预览服务器 | /api 转发保留路径前缀；preview 不提供开发代理 |
| .env.example | 可提交的环境模板，包含 DEV_PORT、DEV_API_TARGET、VITE_API_BASE_URL 和请求超时 | 复制为 .env.local 后修改；VITE_ 变量会进入浏览器，禁止写秘密 |
| .gitignore | 排除 node_modules、dist、日志、本地环境配置和交付包目录 | .env.example 保留在版本管理中 |
| start.cmd | Windows 启动脚本，检查 Node.js，需要时安装依赖，再启动 Vite | 默认访问地址为 5174；修改 DEV_PORT 后以终端实际地址为准 |
| deploy/nginx.conf.example | 正式部署参考：托管 dist，将 /api/ 转发给后端 | backend:8080 是占位地址；HTTPS 和证书需部署环境配置 |
| scripts/package.mjs | 按白名单复制源码并压缩，生成文件清单和 ZIP 校验文件 | 当前打包命令依赖 Windows PowerShell，ZIP 可跨平台解压 |

环境变量修改后，需要重启 npm run dev。只改代理地址不会自动从演示切到真实业务。

## 后端联调时应改哪里

| 任务 | 主要入口 | 双方需要确认 |
| --- | --- | --- |
| 切换后端地址 | .env.local 的 DEV_API_TARGET | 地址、端口、/api 前缀 |
| 调整响应结构 | api/http.js | 唯一成功码、分页、错误码 |
| 修改路径或请求参数 | api/index.js | OpenAPI 与文档约定 |
| 商品和类目换成数据库数据 | useMarketplace.js、api/index.js | 商品/类目 ID、学校、图片、分页、排序 |
| 正式登录 | App.vue、useMarketplace.js、api/index.js | 登录表单、Token、角色、过期和退出 |
| 购物车与下单 | useMarketplace.js、api/index.js | cartItemId 与 productId、地址 ID、服务端金额与库存 |
| 接商品图片 | App.vue、商品展示组件 | 图片 URL、上传、失败占位 |
| 正式部署 | deploy/nginx.conf.example | 域名、后端地址、HTTPS |

后端一般不需要改页面样式和 SVG 插画。接口实现后，由前端负责人调整状态逻辑与展示适配。

## 生成目录和包内排除项

node_modules/ 是安装依赖后生成的目录；dist/ 是 npm run build 生成的发布文件；交付包/ 是重新打包后生成的目录。这些不应作为源码重复发送。

交接 ZIP 不包含 node_modules、dist、.env.local、后端源码、数据库或服务端密钥。后端组员在解压目录执行 npm ci 还原依赖。

## 常用命令

    npm ci                  # 根据锁文件安装依赖
    npm run dev             # 本地开发，默认 5174
    npm test                # 验证 HTTP 请求层
    npm run build           # 输出 dist
    npm run preview         # 预览 dist，默认 4174
    npm run handoff:pack     # Windows 下重新生成源码交接 ZIP
